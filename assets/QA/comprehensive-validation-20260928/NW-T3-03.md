## Scope

This bounded run covered nine live convolutional definitions through four real Builder graphs:

- Conv1D → Average Pooling 1D → Global Pooling 1D, Keras API over PyTorch.
- Conv2D → Max Pooling 2D → Global Pooling 2D, Keras API over PyTorch.
- Conv3D → Average Pooling 3D → Global Pooling 3D, Keras API over PyTorch.
- The same Conv2D graph through the native PyTorch API.

The run checked the live catalog, Builder search and materialization, rendered Inspector state, connection validation, static shapes and parameter counts, save/reload persistence, Functional Validation, exact worker identity, browser errors, and cleanup.

This is not a full convolutional-catalog certification. Source generation, export artifacts, invalid repair, profile switching, training, assistive technology, all six live profiles, and the remaining convolutional definitions were not claimed.
