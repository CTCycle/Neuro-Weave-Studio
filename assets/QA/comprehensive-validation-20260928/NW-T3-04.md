## Scope

This run covered the nine remaining live convolutional definitions after
NW-T3-03, plus one native-PyTorch neighbor for depthwise convolution:

- Max Pooling 1D, Average Pooling 2D, and Max Pooling 3D.
- Depthwise, Separable, and Transposed Convolution.
- Upsampling, Padding, and Cropping.
- A duplicate Depthwise case through the native PyTorch API / CPU worker.

Each case used a real Builder project and checked live catalog search and
materialization, rendered Builder state, input-to-node-to-output connections,
static validation, exact parameter count, save/reload persistence, exact
worker identity, Functional Validation, runtime output shape, browser errors,
and project deletion. The browser matrix ran serially with one worker.

This is a bounded catalog slice, not full Model Builder certification. It does
not claim all parameters, incompatible-edge pairs, all six live profiles,
source or export artifacts, training, assistive technology, or the remaining
catalog families.
