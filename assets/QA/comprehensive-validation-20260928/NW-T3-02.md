## Defect found and fixed

The first live run exposed a real implementation mismatch: static inference
reported `672` parameters while the successful Keras/PyTorch worker reported
`696`. The 24-parameter difference was the second GRU bias vector required by
Keras' default `reset_after=true` behavior. The fix in
`app/server/validation/shape_inference.py` counts two GRU bias vectors when
`reset_after` is enabled and one when it is disabled. The regression now covers
GRU counts `312` (`reset_after=true`) and `288` (`reset_after=false`), while
Simple RNN remains `96` and LSTM remains `384`.

The initial failing run is retained in [the discovery log](logs/recurrent-variants-e2e.log);
the focused rerun passed and the full three-case serial suite passed after the
fix. The code and regression test are committed in `4ec01814`.
