Restoring `layers=1` saved at revision 2, reloaded with the repaired value, and completed job `9e53ec3f76844b1ea20d2b7b68ac82d3` successfully. See [invalid](evidence/nw-t3-06-attention/nw-t3-06-invalid-layers.json) and [repaired](evidence/nw-t3-06-attention/nw-t3-06-repaired-layers.json) receipts.
- Native Dropout is visibly marked `Fixed to 0 by this backend.` and the control is disabled; the browser case submitted no job. The focused backend contract separately rejects an authored native `dropout=0.25` with `unsupported_parameter_option`, so the value is not silently dropped.
- Focused static coverage also rejects non-rank-3 attention inputs, empty/zero/negative output shapes, missing cross-attention Context, and the `layers=2` boundary. Bias-free native parity verifies the expected parameter count `256` across the available parity backends.
