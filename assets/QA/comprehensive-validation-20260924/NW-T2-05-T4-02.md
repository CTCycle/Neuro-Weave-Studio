## NW-T2-05 — PASS

The official Windows launcher served the current application on backend port 9750 and preview port 6425 with an isolated database and tensor-inspection root. The browser workflow validated a saved sequence graph, then opened the inspector from both Builder and the model overview. Both entries used the exact Keras/PyTorch profile and seed 42. The session exposed the recurrent node's `output` and `hidden_state` ports, reported initialized untrained weights, and left the saved graph and revision unchanged.

The rendered slice selected axes 1 and 2 from the `[1, 3, 4]` output, returned `view_shape: [3, 4]`, and displayed 12 cells in three rows and four columns. The workflow also verified the 64-bin histogram, hidden-state shape `[1, 4]`, identical values across the two entry points, explicit session deletion (`204`, followed by `404`), and cancellation of an active inspection without publishing a session. The API rejected a request for a noncurrent project revision with the typed `revision_conflict` response before worker submission. See the [rendered heatmap](evidence/nw-t2-05/nw-t2-05-builder-sequence-heatmap.png) and [browser log](logs/nw-t2-05-browser-e2e-20260924.log).

Three focused service tests covered persisted node/port traces and filesystem storage, finite-only statistics and JSON-safe non-finite slices, invalid axis bounds, sampled and summary-only limits, retention cleanup, expiry, and deletion. Two parameter cases also rechecked fail-closed native compiler rejection. All five passed; see the [backend test log](logs/nw-t2-05-backend-focused-20260924.log).

Visual validation caught two UI defects during this pass. The heatmap had fixed 64-column CSS even when the server returned a smaller exact slice, and native select controls could display their first option while the coordinator had selected another node or axis. The heatmap now derives its column count from `view_shape`, and the node and axis options reflect the selected values. The E2E gate asserts the selected node, axes, and rendered 3-by-4 cell geometry.
