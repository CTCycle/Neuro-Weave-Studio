# System Overview

Last updated: 2026-07-30

The repository contains a FastAPI backend in `app/server/neuro_weave`, a React TypeScript frontend in `app/client/src`, manifest resources in `app/server/neuro_weave/resources/nodes`, example projects in `app/resources/examples`, and focused documentation under `assets/docs`. The backend owns graph contracts, validation, compilation, persistence, and exports. The frontend owns editing state and interaction, but backend validation remains authoritative.
