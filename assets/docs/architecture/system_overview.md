# System Overview

Last updated: 2026-07-30

The repository contains a FastAPI backend in `backend/neuro_weave`, a React TypeScript frontend in `frontend/src`, manifest resources in `backend/neuro_weave/resources/nodes`, example projects in `examples`, and focused documentation under `assets/docs`. The backend owns graph contracts, validation, compilation, persistence, and exports. The frontend owns editing state and interaction, but backend validation remains authoritative.
