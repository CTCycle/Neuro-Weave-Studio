# System Overview

Last updated: 2026-08-02

The repository contains a flat FastAPI backend in `app/server`, a database initializer in `app/scripts`, a React TypeScript frontend in `frontend/src`, manifest resources in `app/server/resources/nodes`, example projects in `examples`, and focused documentation under `assets/docs`. The backend owns graph contracts, validation, compilation, persistence, and exports. The frontend owns editing state and interaction, but backend validation remains authoritative.
