# Vision and Scope

Last updated: 2026-07-30

NeuroWeave lets non-programmers construct valid machine-learning architectures as directed acyclic graphs. The MVP edits architecture, validates contracts and tensor shapes, persists versioned projects, generates source, and exports an untrained Keras model for a constrained subset. Dataset handling, training, evaluation, deployment, arbitrary custom code, and cross-framework conversion are outside the MVP. The system must never label an architecture-only artifact as trained.
