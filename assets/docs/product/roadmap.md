# Roadmap

Last updated: 2026-07-30

Phase 1 is the implemented architecture editor. Phase 2 adds dataset metadata, training configuration, local training jobs, evaluation, and experiment tracking. Phase 3 adds a signed plugin model and custom nodes. Phase 4 adds deployment and additional exporters such as ONNX, JAX or Flax, TensorFlow Lite, TorchScript, Core ML, and OpenVINO. Each phase must extend the canonical graph rather than bypass it.
