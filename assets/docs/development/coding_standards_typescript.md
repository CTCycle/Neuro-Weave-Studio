# TypeScript Coding Standards

Last updated: 2026-07-30

Use strict TypeScript, function components, typed API boundaries, and editor-domain modules. Avoid `any` in domain contracts. Keep backend field names stable at API boundaries. Canvas behavior belongs in store actions and editor components, not ad hoc event closures. Maintain keyboard accessibility and reduced-motion behavior. ESLint, Vitest, and the production TypeScript build are required gates.
