# Domain Ontology

Last updated: 2026-07-30

A Project owns one current Model Graph and a history of revisions. A Model Graph contains Node Instances, Edge Instances, model-level configuration, and export settings. A Node Instance references exactly one versioned Node Definition. A Backend identifies a target framework. An Exporter translates the canonical graph or compiled IR to one backend representation. Validation Diagnostics describe errors, warnings, compatibility notices, or information.
