# Node Taxonomy

Last updated: 2026-07-30

Built-in categories are inputs, core, convolutional, recurrent, transformer, merge, mathematical, and outputs. Categories organize discovery and documentation but do not control execution. Node behavior is defined by the manifest identity, ports, parameters, shape rule, and framework mappings. Model-level optimizer, loss, metric, regularizer, initializer, constraint, learning-rate, and mixed-precision concepts are configuration rather than tensor nodes.
