# Node Taxonomy

Last updated: 2026-09-01

Built-in categories are inputs, core, convolutional, recurrent, transformer, merge, mathematical, and outputs. Categories organize discovery and documentation but do not control execution. Output-category nodes are optional output adapters; a regular computational node can terminate a graph and be selected as an output. Node behavior is defined by the manifest identity, ports, parameters, shape rule, semantic role, and framework mappings. Model-level optimizer, loss, metric, regularizer, initializer, constraint, learning-rate, and mixed-precision concepts are configuration rather than tensor nodes.
