# Convolutional Layers

Last updated: 2026-07-30

The catalog includes Conv1D, Conv2D, Conv3D, transposed, depthwise, and separable convolution, max and average pooling, global pooling, upsampling, padding, and cropping. MVP shape inference enforces convolution rank and channel replacement but intentionally does not claim exact spatial output inference for every padding, dilation, stride, and framework combination.
