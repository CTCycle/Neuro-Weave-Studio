# Accessibility

Last updated: 2026-09-09

Inputs have labels, dialogs expose roles, focus remains visible through native controls, and reduced-motion preferences disable animation. Diagnostics use text severity and not only color. The full authoring minimum is 1024×768; below that threshold Catalog and Inspector become constrained drawers and the page has no horizontal overflow. Toolbar actions reflow, anchored menus remain within the viewport, and non-canvas targets are at least 24×24px. The graph canvas is a legitimate two-dimensional workspace exception under WCAG Reflow. The Nodes route uses a contained two-pane workspace below global navigation: the catalog toolbar remains visible while the catalog list scrolls independently, and the selected-node details body has its own scroll region. At narrow widths the panes and structured detail fields collapse without horizontal overflow. Context-menu actions expose native disabled state and explanatory titles when an operation is unavailable. Future work must add keyboard-only port connection and canvas traversal.
