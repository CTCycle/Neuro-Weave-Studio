# Accessibility

Last updated: 2026-07-30

Inputs have labels, dialogs expose roles, focus remains visible through native controls, and reduced-motion preferences disable animation. Diagnostics use text severity and not only color. The full authoring minimum is 1024×768; below that threshold Catalog and Inspector become constrained drawers and the page has no horizontal overflow. Toolbar actions reflow, anchored menus remain within the viewport, and non-canvas targets are at least 24×24px. The graph canvas is a legitimate two-dimensional workspace exception under WCAG Reflow. Future work must add keyboard-only port connection and canvas traversal.
